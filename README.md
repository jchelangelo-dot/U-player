# U-player

Android local music player focused on high-quality listening, parametric EQ, and Japanese/anime-song lyrics.

## V1 roadmap
1. Core local playback + MediaSession
2. Library / Player UI
3. 10-band PEQ, preamp, headroom and limiter
4. Lyrics: Japanese original + Korean pronunciation + Korean translation
5. Presets and local cache

## Current milestone
Core Player scaffold: MediaStore library scan, Media3 ExoPlayer, MediaSessionService background playback, and initial dark ultramarine UI.

Open the repository root in Android Studio, sync Gradle, grant audio permission, and run on an Android device.
